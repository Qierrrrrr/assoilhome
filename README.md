# ASSOILHOME

> *every feeling deserves a frame*

一个以情绪为驱动的文字生成艺术 Web 应用。用户通过四步引导记录当下的情绪状态，系统将其转化为由文字构成的实时生成图像，并可下载保存或归入个人档案。

**在线体验：** [assoilhome.pages.dev](https://assoilhome.pages.dev)

---

## 使用方法

### 第一步：感受——定位与量化情绪

进入后点击「进入」，来到感受页面。

- **它住在哪里**：点击身体区域（头脑海 / 喉咙 / 胸口 / 胃部 / 双手 / 全身），选择情绪在身体中的感知位置
- **有多强烈**：拖动滑条，从「微微」到「沸腾」量化情绪的强度。强度会实时反映在情绪图谱的节点颜色上——强度越低，选中节点颜色越浅淡；强度越高，颜色越饱和
- **给它一个名字**：右侧是一张力导向情绪图谱，包含 7 大情绪类别（恐惧、愤怒、厌恶、悲伤、孤立、脆弱、困惑）及其细分标签，每个类别有对应的名画色彩
  - 点击节点选中情绪（可多选）
  - 点击大类圆圈可一键选中该类下所有细分情绪
  - 按住节点可拖动重排图谱布局

完成后点击「继续 →」。

---

### 第二步：书写——让它说话

在文本框中自由书写任何内容，没有格式要求，没有对错之分。文字将成为后续生成图像的唯一原材料——效果只使用你写下的文字循环呈现，不会用其他词语填充。

> 字数上限 2000 字。使用「游走」效果时有多少字做多少字的特效，建议输入 50～350 字以获得最佳效果。

点击「绘制 →」进入生成页面。

---

### 第三步：生成——调整与导出

画布左侧是可编辑的文字面板（修改内容不会触发重新生成），右侧控制面板可调整以下参数：

**画面比例**
- `3:4` 竖版（默认）
- `9:16` 手机全屏比例
- 圆角滑条：调整画面四角的圆弧程度，导出 PNG 时角外区域为透明
- 画布底色：黑 / 米白 / 白，独立于色调设置

**效果**（三选一）

| 效果 | 交互方式 | 说明 |
|------|----------|------|
| 书写 | 在画布上按住鼠标拖动 | 文字字符沿鼠标轨迹流动书写，速度越快字号越大，可多笔连续书写 |
| 钟摆 | 按住鼠标拖出路径后松开 | 链式钟摆沿路径摆动，末端轨迹留字，字色随名画调色板循环；Delete/Backspace 清空画面 |
| 游走 | 鼠标左右移动 | 词语以噪声漫游于画面，鼠标右移时词语逐渐归位还原原文排版；相同词性的词以折线相连 |

- **速度/力度**滑条：控制效果的动态强度

**色调**（17 幅名画预设，默认莫奈《撑阳伞的女人》）

从 17 幅世界名画中提取调色板，包括梵高《星夜》、蒙克《呐喊》、毕加索《亚威农少女》、伦勃朗《夜巡》等。每张卡片展示 5 个色块，可单独点击开关某个色块，最少保留 1 个。

**边框**（四选一）

| 边框 | 说明 |
|------|------|
| 无边框 | 纯净画面 |
| 邮票 | 四周锯齿穿孔，颜色随画布底色自动适配 |
| 胶片 | 左右两侧竖向胶片条，黑色固定（还原真实胶片材质） |
| 撕裂 | 四边不规则颗粒边缘，颜色随画布底色自动适配 |

---

### 第四步：保存与归档

| 按钮 | 功能 |
|------|------|
| 下载图片 | 导出当前画面为高清 PNG（设置了圆角时角外透明） |
| 下载视频 | 录制高码率 VP9 视频并下载（最长 30 秒，手动点击停止或自动停止） |
| 归档查看 | 弹出标题输入框，可为本次记录命名后存入本地档案，跳过则默认「未命名」 |
| 再次记录 | 清空所有状态，返回首页重新开始 |

**归档页功能：**
- 点击任意卡片弹出大图，查看完整记录：标题、情绪类别与标签、身体位置、情绪强度、书写内容
- 在弹窗中直接点击标题可编辑，失焦后自动保存
- 点击「选择」进入多选模式，勾选后可批量删除
- 归档存储完整的情绪记录，包含身体位置与强度信息

## 注意事项

- **归档数据存储在浏览器本地**（LocalStorage），清除浏览器数据后归档将丢失，建议重要作品及时下载保存

- **视频录制**依赖 `MediaRecorder` API，部分旧版浏览器可能不支持；推荐使用 Chrome / Edge 最新版

- **钟摆效果**路径长度会影响生成质量，建议拖出至少覆盖画面 1/3 的路径再松开

- **游走效果**词语数量与输入文字直接对应，输入内容越多，画面越丰富
