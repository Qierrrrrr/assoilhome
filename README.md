# ASSOILHOME

> *every feeling deserves a frame*

一个以情绪为驱动的文字生成艺术 Web 应用。用户通过四步引导记录当下的情绪状态，系统将其转化为由文字构成的实时生成图像，并可下载保存或归入个人档案。

**在线体验：** [assoilhome.pages.dev](https://assoilhome.pages.dev)

---

## 使用方法

### 第一步：感受——定位与量化情绪

进入后点击「进入」，来到感受页面。

- **它住在哪里**：点击身体区域（头脑海 / 喉咙 / 胸口 / 胃部 / 双手 / 全身），选择情绪在身体中的感知位置
- **有多强烈**：拖动滑条，从「微微」到「沸腾」量化情绪的强度
- **给它一个名字**：右侧是一张力导向情绪图谱，包含 7 大情绪类别（恐惧、愤怒、厌恶、悲伤、孤立、脆弱、困惑）及其细分标签
  - 点击节点选中情绪（可多选）
  - 点击大类圆圈可一键选中该类下所有细分情绪
  - 按住节点可拖动重排图谱布局

完成后点击「继续 →」。

---

### 第二步：书写——让它说话

在文本框中自由书写任何内容，没有格式要求，没有对错之分。文字将成为后续生成图像的原材料。

> 字数上限 2000 字。使用「游走」效果时建议输入 100～350 字以获得最佳效果。

点击「绘制 →」进入生成页面。

---

### 第三步：生成——调整与导出

画布左侧是可编辑的文字面板（修改内容不会触发重新生成），右侧控制面板可调整以下参数：

**画面比例**
- `3:4` 竖版（默认）
- `9:16` 手机全屏比例
- 圆角滑条：调整画面四角的圆弧程度

**效果**（三选一）

| 效果 | 交互方式 | 说明 |
|------|----------|------|
| 书写 | 在画布上按住鼠标拖动 | 文字字符沿鼠标轨迹流动书写，速度越快字号越大 |
| 钟摆 | 按住鼠标拖出路径后松开 | 链式钟摆沿路径摆动，末端轨迹留字；Delete/Backspace 清空画面 |
| 游走 | 鼠标左右移动 | 词语以噪声漫游于画面，鼠标右移时词语逐渐归位还原原文排版；相同词性的词以折线相连 |

- **速度/力度**滑条：控制效果的动态强度

**色调**（六选一）
烈焰 · 寒蓝 · 虚空 · 胆汁 · 灰烬 · 血色

**边框**（四选一）
无边框 · 邮票 · 胶片 · 撕裂

---

### 第四步：保存与归档

| 按钮 | 功能 |
|------|------|
| 下载图片 | 导出当前画面为高清 PNG |
| 下载视频 | 录制 5 秒高码率 VP9 视频并下载 |
| 归档查看 | 将当前图像存入本地档案，并跳转至归档页浏览历史记录 |
| 再次记录 | 清空所有状态，返回首页重新开始 |

归档页中点击任意记录可弹出大图，查看当时的情绪标签与书写内容。

---

## 注意事项

- **归档数据存储在浏览器本地**（LocalStorage），清除浏览器数据后归档将丢失，建议重要作品及时下载保存

- **视频录制**依赖 `MediaRecorder` API，部分旧版浏览器可能不支持；推荐使用 Chrome / Edge 最新版

- **钟摆效果**路径长度会影响生成质量，建议拖出至少覆盖画面 1/3 的路径再松开

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架）
- [p5.js](https://p5js.org/) — 生成艺术画布
- [opentype.js](https://opentype.js.org/) — 字形轮廓解析
- Noto Serif SC — 中文衬线字体
